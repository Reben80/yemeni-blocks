# Yemeni Blocks

A quarter-turn tiling puzzle. Cover every square with 32 bricks so each colour is one connected shape. Turn the board a quarter turn around the centre and the colours cycle: red lands on yellow, yellow on blue, blue on white, and white on red.

There are 64 cards, from a full outline (Starter) to almost no help (Master).

Play it at [reben80.github.io/yemeni-blocks](https://reben80.github.io/yemeni-blocks/).
